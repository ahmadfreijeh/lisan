لسان lisan

A lightweight macOS tool that transliterates Latin-typed words to Arabic instantly, right where you're typing.

marhaba + Space ■ مرحبا
GitHub Installation

Features

  • Instant swapType a word, hit Space — it's replaced with Arabic directly in the field, no copy/paste.
  • No lagA "…" placeholder appears immediately while the lookup runs, then gets replaced.
  • SuggestionsPress F2 right after a swap to cycle through alternate Arabic candidates.
  • Menu bar appToggle lisan on/off from a menu bar icon, no terminal needed.
  • App filterRestrict it to one app (e.g. WhatsApp, Notes) via the menu or --app.
  • PrivateNo clipboard, no storage — only the typed word is sent to Yamli for transliteration.

Installation

  1. Clone the repo and install dependencies. 
    git clone https://github.com/ahmadfreijeh/lisan.git
cd lisan
pip3 install -r requirements.txt
  2. Grant macOS permissions: Accessibility + Input Monitoring, under System Settings, Privacy & Security, for the exact Python binary running the script (it prints the path on first run).
  3. Run it. 
    python3 lisan_app.py          # menu bar app
python3 lisan.py              # terminal script
python3 lisan.py --app Notes  # restrict to one app
  4. Type a Latin word (e.g. marhaba), press Space — it becomes Arabic.
lisan is open source — source & docs on GitHub.
