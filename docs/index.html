لسان lisan

Type Arabic using your normal Latin keyboard, in any macOS app.

Write a word the way it sounds, press Space, and lisan replaces it with the Arabic spelling right where your cursor is — no copy/paste, no switching keyboard layouts.

marhaba + Space → مرحبا
Install How to use Menu bar Troubleshooting GitHub

What you get

  • Works everywhere. Notes, WhatsApp, Messages, Mail, Safari, and any other text field.
  • Type as it sounds. shukran gives شكرا, kitaab gives كتاب — one word at a time, as you go.
  • Other spellings. If the Arabic word isn't the one you meant, press F2 to cycle through alternatives.
  • On/off whenever you want. A menu bar icon starts and stops it; it does nothing while stopped.
  • One app only, if you prefer. Limit lisan to a single app, like WhatsApp.
  • Nothing is saved. Only the word you just typed is sent to Yamli to be converted. No clipboard, no history, no account.

You need macOS and Python 3.9 or newer. Check with python3 --version in Terminal.

Install

1. Download lisan

Open Terminal and paste these lines, one at a time:

git clone https://github.com/ahmadfreijeh/lisan.git
cd lisan
pip3 install -r requirements.txt

2. Start it

python3 lisan_app.py

A لسان icon appears in your menu bar. The first run prints a file path in Terminal that looks like /usr/local/bin/python3 — keep that window open, you need the path in the next step.

3. Give it permission to type for you

macOS has to allow lisan to read your keystrokes and type the Arabic word back. Open System Settings → Privacy & Security and add the path from step 2 in both of these places:

  • Accessibility
  • Input Monitoring

In the file picker, press Cmd + Shift + G and paste the path — these Python files are normally hidden.

Then quit lisan and start it again. macOS only checks permissions when an app launches.

4. Try it

Click the menu bar icon, choose Start, open Notes, type marhaba and press Space.

How to use it

You do thisWhat happens
Type a word, press SpaceThe Latin word is replaced with Arabic, followed by a space.
Press F2 right afterSwaps in the next possible Arabic spelling. Keep pressing to keep cycling.
Type punctuation, Enter, or an arrow keyEnds the current word. Nothing is converted.
Press Space twiceNothing to convert, so you just get a space.

You'll see a short … in place of your word while lisan looks it up. It disappears once the Arabic arrives, usually instantly. If no Arabic match is found, your original word comes back unchanged.

F2 only works immediately after a swap. Once you type something else, lisan no longer knows where that word was.

The menu bar icon

Menu itemWhat it does
Start / StopTurns lisan on and off. It ignores your typing completely while stopped.
Run inLimits lisan to one app — All Apps, Notes, WhatsApp, Messages, Mail, Safari, or Custom App… for anything else. Takes effect right away.
SuggestionsLists the other Arabic spellings for the word you just converted. Click one to use it instead of pressing F2.
QuitStops lisan and closes the app.

A checkmark in Run in shows which app is currently active. The icon shows a checkmark when lisan is running.

Prefer the Terminal?

You can run lisan without the menu bar app. It starts working immediately and stops with Ctrl + C.

python3 lisan.py                  # active in every app
python3 lisan.py --app Notes      # only while Notes is in front
python3 lisan.py -a WhatsApp      # only while WhatsApp is in front

App names are matched loosely and ignore capitalisation, so -a whats also works.

Troubleshooting

Nothing happens when I press Space

This is almost always the permissions step. Confirm the exact Python path printed in Terminal is listed under both Accessibility and Input Monitoring, and that the switch next to it is on. Then quit lisan and start it again.

It worked yesterday and stopped today

If you updated macOS or Python, the old path may no longer match. Start lisan, read the new path it prints, and add that one.

It does nothing in a password field

Expected. macOS blocks all apps from typing into secure fields. lisan can't work there, and shouldn't.

I get the wrong Arabic word

Press F2 or use the Suggestions menu. It also helps to spell the word closer to how it sounds — kitaab tends to work better than ktb.

It converts words when I don't want it to

Click Stop, or use Run in to limit lisan to the one app where you write Arabic.

Privacy

lisan runs on your Mac and watches keystrokes only while it's started. When you press Space, the single word you typed is sent to Yamli to get the Arabic spelling. Nothing is written to disk, nothing goes to the clipboard, and there is no account or sign-in.

lisan is free and open source. Read the code, report a problem, or suggest a change on GitHub.
