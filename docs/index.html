What it does

⚡️

Instant, in place

Type a Latin word, hit Space, and it's swapped for Arabic directly in whatever field you're using — no copy/paste.

…

No lag feeling

An instant "…" placeholder appears the moment you hit Space, then gets replaced once the lookup finishes.

🔁

Alternate suggestions

Press F2 right after a swap to cycle through other Arabic candidates for that word.

🧭

Menu bar app

Run it as a toggleable menu bar icon instead of a terminal script — Start/Stop whenever you want.

🎯

Restrict to one app

Only want it active in WhatsApp or Notes? Pick from the menu, or pass --app on the CLI.

🔒

No clipboard, no cloud storage

Text is swapped via direct keystroke simulation. Only the typed word itself is sent to Yamli for transliteration.

Installation

  1. Clone the repo and install dependencies: 
    git clone https://github.com/ahmadfreijeh/lisan.git
cd lisan
pip3 install -r requirements.txt
  2. Grant macOS permissions. lisan needs Accessibility + Input Monitoring access (System Settings → Privacy & Security) for the exact Python binary running it — the script prints the exact path to add.
  3. Run it — either as a menu bar app, or straight from the terminal: 
    python3 lisan_app.py     # menu bar app, with Start/Stop + suggestions
python3 lisan.py         # terminal script
python3 lisan.py --app Notes   # restrict to one app
  4. Type and go. Type a Latin word (e.g. marhaba), press Space, and it becomes Arabic where you're typing.

lisan is open source — source, issues & docs on GitHub.
